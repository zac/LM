## Smithsonian panorama

User link: https://airandspace.si.edu/multimedia-gallery/panorama/lm-interiorjpg . Official indexed page identifies the interior as LM-2. The museum object record https://airandspace.si.edu/collection-objects/lunar-module-2-apollo/nasm_A19711598000 says LM-2 never flew and was modified to appear like Apollo 11 Eagle. Use it for physical interior relationships/material/detail comparisons with this restoration qualification, not a mission-exact LM-5 survey. Panorama imagery rights are page-specific; no blanket reuse license inferred.

## Phase application

- Cabin: compare enclosure silhouette, ceiling treatment, floor/hatch intrusions, standing space and side-panel depth. Avoid a smooth empty cylinder as the final visual character.
- PanelInventory: compare strong sideward/overhead tiers, panel density and station-relative placement. Retain labels/placeholders for unbuilt equipment instead of inventing a complete control catalog.
- WindowsLPD: compare frame depth, rounded inner corners, thin markings and relative visual prominence. Separate actual photo evidence from the apparent render in the collage.
- Presentation: use physical photo/museum evidence for restrained materials/lighting; do not copy simulated digital indications or museum lighting as historical truth.

The user permits approximate but credible geometry. These sources inform review and future refinement; they do not automatically invalidate agreed numeric interfaces or authorize arbitrary scale changes.
