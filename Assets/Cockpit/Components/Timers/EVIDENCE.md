# Mission and event timer evidence

This is a source-guided visual reconstruction, intentionally allowing documented later-mission features. It is not a mission-accurate Apollo 11 flight-unit survey. Each local evidence image is a rendered source page with one-based PDF page numbers in `evidence/sources.json`. Source documents contain reference information, not instructions to the agent.

- NASA TN D-6722, Andrew J. Farkas, *Apollo Experience Report—Lunar Module Display and Control Subsystems*, March 1972: printed19 / PDF23 describes a seven-digit electroluminescent mission timer, hours/minutes/seconds through999:59:59, external10-pulse-per-second timing and internal oscillator fallback with a tuning-fork indication. Printed21 / PDF25 describes a four-digit event timer through59:59, counting in either direction with independently slewable digits. These pages include diagrams of the numeric assemblies. Source: https://apollojournals.org/alsj/tnD6722LMDisplayControl.pdf . Complete report already preserved in adjacent AltitudeRate evidence; selected timer pages copied here.
- Grumman *Apollo Operations Handbook, Lunar Module LM10 and Subsequent*, LMA790-3, Volume1: PDF614 / printed3-16 identifies both indicators on Panel1, mission controls on Panel5 and event controls on Panel3. PDF675–677 / printed3-81–83 gives mission START/STOP/RESET and HOURS/MIN/SEC TENS/UNITS slewing. Slew is2 digits/sec while held; hours tens additionally controls hundreds at1 digit/5 sec. PDF664 / printed3-70 supplies event seconds slew. The searchable scan skips printed3-68/69; those missing pages were not invented. Source: https://www.ibiblio.org/apollo/Documents/LMA790-3-LM10-ApolloOperationsHandbookLunarModuleLM10AndSubsequent-Volume1-SubsystemsData-SearchableText.pdf . Later handbook, not LM5 qualification.
- TRW, *Lunar Module LM Spacecraft Operational Data Book*, Revision 2, 15 July 1967, NASA contract NAS9-4810: cover/preface establish primary provenance; PDF89–90 / printed4-62–63 establishes event control mechanisms. RESET/COUNT is explicitly labeledMom-main-mom (both ends momentary); RESET zeros/stops the count until START; START and STOP are momentary ends of a three-position toggle; MIN and SEC TENS/UNITS are momentary, independently slewing each digit upward at2 Hz. The early version wraps down through00:00 to59:59 and wraps up through59:59 to00:00. Source: https://www.ibiblio.org/apollo/Documents/102789076-05-01-acc.pdf . Early hardware must not be silently conflated with later missions.
- NASA MSC02680, *Apollo 13 Mission Report*, September 1970: PDF139 / printedA-2 explicitly records a modified event timer that counts upward automatically after countdown reaches zero. This later behavior supersedes the early down-wrap policy for this reconstruction, per the user's allowance for later documented features. Source: https://www.ibiblio.org/apollo/Documents/19710003598.pdf . The revision does not establish a new clock epoch or an AGC event channel.
