# Solid console enclosure integration

Status: runtime compiled against draft resources; native regression and visual acceptance pending immutable LMKit delivery. This is not a final appearance qualification.

Three independent Cabin-relative overlays replace the shallow skeletal console surfaces without moving an instrument, mount, window, or input target. InstrumentConsole requires both live FDAIs. LowerConsole requires the live DSKY and ACA. WindowSurrounds requires the validated foundation optical interfaces. Each failed load leaves the prior surfaces and successful peers intact.

`LMCockpitConsoleEnclosure` validates the identity meter-space root, explicit replacement and protected-datum path sets, disjoint geometry groups, and absence of input/light components. Assembly installation resolves every root-relative pose and validates all replacements before attaching or hiding anything. Only surface groups, exact placeholder children, and named Cabin leaf meshes are suppressed. Structural coverage makes no slot-occupancy or functional-completion claims. Existing instrument instances and planning annotations remain intact.

Closed enclosure groups retain the established physically based painted-structure treatment and cast shadows. After successful installation the scene invalidates the fitted shadow bounds, excludes disabled old shell leaves, and includes the declared new caster groups. Sun intensity, direction, simulation, and the accepted local cockpit/lander shadow policy are unchanged.

Normal startup loads all three. `--no-console-enclosures` is an inspection comparison option; `--procedural-cockpit` continues to select the procedural fallback. Installation evidence records enclosure IDs, qualified suppressed paths, and caster groups to distinguish a successful native render from a silent load fallback.

Focused tests cover exact successful suppression, protected mount/occupancy preservation, shadow policy, late-pose rollback and retry, unexpected path rejection, duplicate/input protection, overlapping groups, invalid root values, and scene live-instrument gating. Final acceptance must combine these with the prior 98 regression cases and native commander, pilot and oblique views. Geometry and load tests alone cannot establish solid embedding or correct normals.

Known source constraints remain: provisional panel layout, differing commander/pilot FDAI seating, deep instrument housings intersecting provisional rear shell, inactive unsupported hardware, and no headset legibility qualification. The enclosure phase must not conceal these limitations through altered control poses or invented behavior.
